# Home

My `~`, version-controlled with git.

## What's inside

- **Dotfiles**: shell, editor, terminal, and tool configs
    - `.bashrc`, `.config/fish` etc.

- **Notes**: programming languages, operating systems, misc.

- **[Retain](./retain)**: generates `.gitignore` from a whitelist.

## How it works

Everything is ignored by default. Only paths declared in `retain/white_list.py` are tracked.
